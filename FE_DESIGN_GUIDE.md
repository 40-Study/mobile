## 1.1 Dashboard Giáo viên

**Route:** `/teacher/dashboard`

**APIs:**
```
GET /auth/me                    → Thông tin user
GET /auth/profiles              → Danh sách profiles
```

|------------|---------------|

| Tổng học sinh | Tính tổng `student_count` từ các lớp |
| Buổi học hôm nay | `GET /classes/:id/schedules` filter theo ngày |
| Danh sách lớp | `GET /classes` → `classes[]` |

## Tổng hợp Routes & APIs

### Giáo viên (TEACHER)

| Route | Trang | APIs |
|-------|-------|------|
| `/teacher/dashboard` | Dashboard | `GET /auth/me`, `GET /classes`, `GET /courses` |
| `/teacher/classes` | Danh sách lớp | `GET /classes` |
| `/teacher/classes/:id` | Chi tiết lớp | `GET /classes/:id`, `GET /classes/:id/students`, `GET /classes/:id/teachers` |
| `/teacher/classes/:id/attendance` | Điểm danh | `GET /classes/:id/attendances`, `POST /classes/:id/attendances` |
| `/teacher/classes/create` | Tạo lớp | `POST /classes` |
| `/teacher/profile` | Hồ sơ chuyên môn | `GET /teacher-profiles/:id`, `PUT /teacher-profiles/:id` |
| `/teacher/courses` | Quản lý khóa học | `GET /courses`, `POST /courses` |
| `/teacher/courses/:id/edit` | Chỉnh sửa khóa học | `GET /courses/:id`, `PUT /courses/:id` |
| `/teacher/courses/:id/content` | Quản lý bài học | `GET /courses/:id/sections`, `POST .../lessons` |
| `/teacher/livestream` | Buổi học trực tuyến | `GET /livestream`, `POST /livestream` |
| `/teacher/livestream/:id` | Phòng livestream | `POST /livestream/:id/start`, `GET /chat/:id/messages` |

### Học sinh (STUDENT)

| Route | Trang | APIs |
|-------|-------|------|
| `/student/dashboard` | Dashboard | `GET /auth/me`, `GET /classes`, `GET /enrollments` |
| `/student/classes` | Lớp của tôi | `GET /classes` |
| `/student/classes/:id` | Chi tiết lớp | `GET /classes/:id`, `GET /classes/:id/schedules` |
| `/student/courses` | Khóa học online | `GET /enrollments` |
| `/student/courses/:id/learn` | Học bài | `GET /lessons/:id/video`, `PUT /lessons/:id/progress` |
| `/student/explore` | Khám phá | `GET /courses` |
| `/student/livestream/:id` | Tham gia livestream | `POST /livestream/:id/join` |

### Phụ huynh (PARENT)

| Route | Trang | APIs |
|-------|-------|------|
| `/parent/dashboard` | Dashboard | `GET /auth/me`, `GET /me/children` |
| `/parent/children/:id` | Chi tiết con | `GET /classes`, `GET /classes/:id/attendances` |
| `/parent/children/:id/attendance` | Điểm danh | `GET /classes/:id/attendances` |
| `/parent/children/:id/courses` | Khóa học | `GET /enrollments` |

### Chung

| Route | Trang | APIs |
|-------|-------|------|

| `/forgot-password` | Quên mật khẩu | `POST /auth/reset-password/request`, `POST /auth/reset-password` |
| `/select-profile` | Chọn profile | `GET /auth/profiles`, `POST /auth/switch-profile` |
| `/settings` | Cài đặt | `GET /auth/me`, `PUT /auth/me`, `GET /auth/devices` |
